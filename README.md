# Insurance Fraud Detection ML

A Machine Learning project that predicts whether an insurance claim is potentially fraudulent or legitimate.

## Features

- Insurance claim fraud prediction
- Driver and policy information
- Accident and claim details
- Vehicle and financial information
- Fraud risk prediction
- Confidence score
- Interactive Streamlit UI

## Machine Learning

The project includes:

- Data preprocessing
- Feature selection
- Model training
- Model evaluation
- Model serialization using Pickle
- Streamlit deployment
